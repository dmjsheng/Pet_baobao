# 爆爆桌面宠物：Windows 便携版设计

## 目标

交付一个可在 Windows 10/11 上直接运行的暖色 Q 版桌面宠物应用。用户把整个发布文件夹复制到另一台 Windows 电脑后，也能双击启动，不依赖联网服务、不上传照片或互动数据。

## 角色基准

角色名为“爆爆”：健康、圆润的暹罗母猫，约 7 斤；亲人、粘人，怕生和出门，但认识家人。视觉上锁定用户提供的照片中可辨认的特征：蓝色大眼睛、深棕色面罩/耳朵/四肢/尾巴、奶咖色短毛身体、修长三角耳，以及仰头注视人的表情。最终素材为暖色、干净轮廓的 Q 版，不复制照片背景、相机水印或其他环境物体。

## 技术方案

使用 Electron、TypeScript 和本地 HTML/CSS/Canvas 渲染。`electron-builder` 生成 Windows portable 发布物：用户解压整个发布文件夹后，运行其中的 `爆爆桌面宠物.exe`。

选择 Electron 的原因是它能稳定提供透明无边框窗口、始终置顶、无系统标题栏、跨 Windows 电脑的打包发布和本地文件持久化。应用不包含自动启动、联网、自动更新或远程数据采集。

## 窗口与操作

- 透明、无边框、非缩放的悬浮窗口，默认显示在屏幕右下。
- 始终置顶，可用鼠标拖动宠物本体移动；关闭后再次启动时恢复上次位置。
- 宠物闲置时只有角色可见；将鼠标移到宠物上时，显示小型操作条：`喂食`、`陪伴`、`睡觉`。
- 右键菜单提供：显示/隐藏操作条、重置位置、退出。
- 点击宠物本体视为“抚摸”。

## 状态、互动与中文气泡

| 触发 | 动作/状态 | 气泡示例 |
| --- | --- | --- |
| 默认 | 看着用户、眨眼、轻微歪头 | `我在看你呀` |
| 点击抚摸 | 撒娇、蹭蹭、开心眨眼 | `摸摸就不困啦` |
| 喂食 | 开心期待、满足 | `零食收到！` |
| 陪伴 | 靠近、专注陪伴 | `我在这儿陪你` |
| 睡觉或长时间无互动 | 蜷起睡觉 | `爆爆先眯一会儿` |
| 需要互动 | 期待地看着用户 | `陪我一小会儿嘛` |

气泡由应用界面绘制，短时间自动淡出；它们不写进精灵图，因此不会干扰透明动画素材。

## 动画与视觉资产

按 hatch-pet v2 规范生成爆爆的 11 行精灵图（每格 192×208，总尺寸 1536×2288）：9 种通用动画和 16 个“看向不同方向”的姿态。应用至少使用 idle、waving、jumping、waiting、running、review 等动画来表现上述互动；其余合规动画保留在成品精灵图中。

生成流程以用户的六张照片为身份参考。所有行会保持同一面罩、蓝眼、耳朵、毛色、体形与暖色 Q 版风格。完成前会运行结构校验、透明边缘处理、方向语义校验、动画预览和独立视觉检查。

## 本地状态与隐私

仅在 Windows 用户数据目录保存：窗口坐标、亲密度、最近互动时间和睡眠偏好。互动值只影响气泡和小幅动画选择；不会做健康判断或真实宠物照护提醒。照片仅用于本地构建素材，不被应用读取或随发布包携带。

## 交付内容

- `release/`：可复制到其他 Windows 电脑运行的应用文件夹。
- `source/`：完整应用源码和构建配置。
- `assets/`：最终精灵图、角色配置和必要的应用资源。
- `README-运行说明.md`：运行、复制迁移、关闭和重新构建说明。
- `qa/`：精灵图接触表、方向检查、动画预览与验证结果。

## 错误处理与验收

- 若保存状态损坏，应用回退到默认窗口位置和默认互动值，不阻止启动。
- 若用户把发布文件夹移动到其他目录，应用仍以自身资源路径加载，不依赖开发环境。
- 首次启动、拖动、抚摸、喂食、陪伴、睡觉、右键退出均可在 Windows 上人工验证。
- 发布前验证 portable 构建能在未安装 Node.js 的 Windows 环境中启动；构建期依赖只用于开发。
- 验收时确认透明背景、中文气泡、角色一致性、可拖动性、互动动画、配置持久化和便携运行。

## 范围边界

本期不包含联网、语音识别、摄像头、真实喂食提醒、多宠物管理、开机自启动或手机同步。它们不会在第一版中隐式加入。
