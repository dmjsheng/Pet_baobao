# 爆爆踩奶互动设计

## 目标

将“玩毛线球”完整替换为更符合爆爆粘人性格的“踩奶”互动：她端正坐着，左右前爪交替轻压并偶尔慢眨眼，不再展示毛线球、追逐或扑跳特效。

## 交互与文案

- 操作按钮从“玩毛线球”改为“踩奶”。
- 操作标识从 `yarn` 改为 `knead`，帧动作从 `yarn-chase` 改为 `knead-paws`，避免新功能继续沿用旧语义。
- 气泡文案为“给你踩踩奶～”。
- 点击后播放 8 帧、每帧 170 ms 的一次性踩奶动画，总时长 1.36 秒后恢复闲置状态。

## 视觉

- 生成四个暖色 Q 版暹罗猫坐姿关键帧：左爪下压、右爪下压、左爪下压加慢眨眼、右爪下压加满足表情。
- 躯干、耳朵、尾巴、镜头尺寸、中心和坐姿基线固定；仅前爪、眼睛和极轻微胸口起伏变化。
- 不使用毛线球、食物、玩具、文字、投影或其他道具。
- 输出 8 张透明 `512 × 512` PNG，序列为 `[0, 1, 2, 3, 0, 1, 2, 3]`。

## 兼容与验证

- 保留喂食、陪伴、睡觉、抚摸及闲置动画。
- 移除 yarn 专用 DOM 特效序列与样式，不让无关代码继续执行。
- 新帧的 alpha 边界必须通过既有中心/基线误差不超过 3 px、尺寸差异不超过 2% 的校验。
- 完整测试、构建、便携 EXE 打包和打包资源路径检查必须通过。
- 不执行 Git 提交、推送、合并、重置或配置变更。
