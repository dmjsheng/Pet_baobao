# 爆爆毛线球眼神追踪设计

## 目标

让“玩毛线球”明确读成爆爆在原地追踪移动目标：蓝色虹膜和瞳孔会先看左、再看右，期间加入一次短暂的专注半眯眼；身体、脚掌、画面尺寸和落脚点保持稳定。

## 方案

- 重做 `yarn-chase` 的四个透明关键姿势：左侧追视、左爪试探、右侧追视、右侧专注半眯眼。
- 以 `[0, 1, 0, 2, 3, 2, 0, 1]` 展开为 8 帧；每帧 160 ms，总时长 1.28 秒。
- 保留现有滚动毛线球、追逐、扑跳和回望特效；不改喂食、陪伴、睡觉或闲置动画。
- 复用既有的去色键、固定中心/基线/尺寸对齐和 alpha 边界验证。每帧为透明 `512 × 512`，中心和基线误差不超过 3 px，尺寸变化不超过 2%。

## 成功标准

1. 点击“玩毛线球”时，瞳孔与蓝色虹膜的左右偏移在桌面尺寸下清晰可见。
2. 猫的身体不会缩放、跳动、横移或改变落脚点。
3. 现有毛线球 DOM 特效仍按原时序播放。
4. 帧资源、布局校验、完整测试和便携 EXE 打包均通过。
