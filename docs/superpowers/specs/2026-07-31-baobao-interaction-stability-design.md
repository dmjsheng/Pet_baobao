# 爆爆桌面宠物：互动帧稳定性修复设计

## 问题与目标

现有的抚摸、喂食和毛线球动作帧来自主体大小、位置和姿势差异很大的图像。渲染层对帧动作已经禁用 CSS 变换，因此视觉上的忽大忽小和晃动来自素材本身。

本次将三组问题帧替换成身体位置、大小和脚底落点固定的暖色 Q 版动作帧。动作只体现在眼神、头部、前爪、尾巴和表情的小幅变化，保持交互连贯但不过分打扰。

## 用户可见行为

### 抚摸

- 点击爆爆本体后保持默认站姿大小和位置。
- 六帧表现轻微歪头、眯眼和被摸得舒服的贴贴感；不进行左右平移、放大或缩小。

### 喂食

- 点击“喂食”后保持默认站姿大小和脚底位置。
- 六帧表现注意零食、开心眯眼和短暂满足表情。
- 保留现有零食与爱心浮动特效。

### 毛线球

- 点击“玩毛线球”后保持默认站姿大小和脚底位置。
- 八帧表现目光追随、头部轻转、前爪轻拍和尾巴小幅摆动。
- 保留现有毛线球从一侧滚过的特效；猫不追出画面、不扑跳、不缩放。

## 素材与对齐要求

- `pet-nuzzle`、`eat-treat` 各保留 6 帧，`yarn-chase` 保留 8 帧，均使用连续的 `000.png` 编号。
- 每帧是透明背景的 `512 × 512` PNG。
- 每组所有帧的主体底边相同，水平中心偏差不超过 3 像素，主体宽高偏差不超过 2%。
- 使用现有暖色 Q 版主形象作为风格和比例参考；生成后进行切片、去色键、对齐和接触表视觉检查。
- 拒绝包含相邻格碎片、额外肢体、裁切耳朵或脚爪、背景残留的帧。

## 软件实现

- 不改变 `FrameActionId`、按钮、中文气泡、持久化或静音策略。
- 更新 `FRAME_ANIMATIONS` 的喂食和毛线球帧节奏，使新帧有足够的可读性；抚摸沿用适合六帧的短动作时长。
- `pet[data-animation="frame"]` 继续保持 `animation: none`，确保播放时不受 CSS 缩放、旋转或位移影响。
- 新增一个仅开发期使用的帧布局校验脚本，测量每组 PNG 的 alpha 主体边界并检查对齐与尺寸容差。

## 验收

1. 抚摸、喂食、毛线球播放时，爆爆的整体高度、宽度和脚底落点保持稳定。
2. 喂食有可见的开心反馈，毛线球有可见的追球和拍爪反馈，但没有大幅跑跳。
3. 已有端坐、蜷睡、闲置眨眼、气泡和特效不回归。
4. 帧资源、布局校验、状态机计时、完整测试、构建与便携 EXE 打包全部通过。

## 非目标

- 本次不新增按钮、声音、通知或完整跑跳/扑跳动作。
- 不对闲置、端坐和蜷睡帧做视觉重绘。
