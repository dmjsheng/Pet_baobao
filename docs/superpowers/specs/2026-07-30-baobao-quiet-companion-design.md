# 爆爆安静陪伴互动设计

## 目标

在现有 Windows 桌面宠物中加入低打扰、性格化的连续互动。爆爆默认安静陪伴；她有丰富的自主小动作和用户触发互动，但不会频繁弹窗、播放声音或抢占注意力。

## 行为原则

- 全程静音：不新增猫叫、呼噜、提示音或系统通知。
- 自主行为只改变宠物本体和可选的短气泡，不移动或遮挡其他窗口。
- 用户主动互动立即响应；自主行为受冷却约束。
- 所有时间与互动状态只写入本地用户数据，不联网、不读取摄像头或键盘内容。

## 行为模型

新增独立的行为调度器。它接收当前时间、最近一次用户互动时间、最近一次自主行为时间、睡眠状态和亲密度，输出一次合法的自主行为或“保持安静”。随机选择只在通过冷却门槛后发生，因此不会在每次定时检查时触发。

| 条件 | 行为 | 可见反馈 |
| --- | --- | --- |
| 用户 15 分钟内刚互动 | 保持安静 | 默认看着用户/眨眼 |
| 自主行为后不足 8 分钟 | 保持安静 | 默认动作 |
| 20 分钟没有用户互动 | 自动睡觉 | 蜷起、慢呼吸；不弹气泡 |
| 睡眠中被点击或主动互动 | 醒来 | 伸懒腰、`我醒啦` |
| 通过冷却且清醒 | 随机小动作 | 伸懒腰、左右张望、舔爪或低频求摸摸 |
| 低频求摸摸 | 等待 | 期待地看着用户，气泡 `陪我一小会儿嘛` |

自主小动作以视觉变化为主。只有“求摸摸”允许显示一次、自动消失的中文气泡；其余小动作不显示气泡。

## 主动互动

| 操作 | 连续反馈 | 状态效果 |
| --- | --- | --- |
| 点击爆爆 | 蹭蹭、眨眼 | 亲密度 +1，取消睡眠 |
| 喂食 | 小零食出现 -> 爆爆开心跳跃 -> 两颗小爱心升起 | 亲密度 +2，更新最近互动时间 |
| 陪伴 | 安静歪头、贴近、看着用户 | 亲密度 +1，更新最近互动时间 |
| 睡觉 | 手动入睡/醒来 | 切换睡眠状态 |
| 玩毛线球 | 毛线球滚入 -> 爆爆追逐 -> 小扑跃 -> 停下回看 | 亲密度 +2，更新最近互动时间 |

爱心、零食和毛线球是应用层短暂覆盖元素，具有 `pointer-events: none`，不会阻断拖动或按钮点击。它们不是精灵图的一部分。

## 界面

悬停操作条新增 `玩毛线球`。操作条仍只在悬停或右键菜单显式显示时出现。宠物本体继续可拖动；拖动手势优先于点击，发生明显位移时不视为一次抚摸。

## 持久化

扩展本地状态，保存：窗口位置、亲密度、最近用户互动时间、最近自主行为时间、睡眠状态。重启后会保留睡眠状态与冷却时间，不会刚打开就主动弹气泡。

## 测试与验收

- 用纯函数测试行为调度：15 分钟安静期、8 分钟自主冷却、20 分钟自动睡眠、睡眠状态排他性。
- 用纯函数测试主动互动：喂食和毛线球增加亲密度并记录用户互动时间。
- 用纯函数测试效果队列：喂食的 `treat -> hearts`，毛线球的 `yarn-ball -> chase -> pounce`。
- 测试渲染器打包后不含浏览器不支持的 CommonJS `require()`。
- 在 Windows 手工验证：连续点击、喂食、陪伴、睡觉、玩毛线球、拖动、长时间闲置、重启后冷却。

## 范围边界

本期使用现有爆爆主视觉与 CSS/DOM 组合动画；不重新生成完整 11 行精灵图，不添加音效、开机启动、联网、真实喂食提醒或系统通知。
